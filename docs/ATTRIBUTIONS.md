## Curation rules

1. **CC0 first.** Prefer CC0 sources. Most desirable: Kenney.nl, Pixabay (CC0 ones), Mixkit (CC0 audio), Sketchfab CC0 filter, Modrinth packs explicitly tagged CC0.
2. **CC-BY with attribution.** Acceptable but each entry MUST be listed here with the author and source URL. The pack ships a `LICENSES.txt` mirror that includes the same attributions.
3. **No implicit re-use.** "Found on Pinterest", "borrowed from a Discord server", "ripped from a popular pack" — all rejected.
4. **Modify, don't redistribute.** When we tweak a CC-BY texture, both the original attribution and the change description must be recorded.
5. **In-house assets.** Anything generated by our own scripts (`scripts/gen-*.py`) or hand-built from scratch is licensed CC0 to the project.
